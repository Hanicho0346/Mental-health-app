1. Clone the repository:

git clone https://github.com/Hanicho0346/Mental-health-app.git

2. Navigate to the project folder:

cd Mental-health-app

3. Run the frontend Expo application:

cd client
npm install
npx expo start

4. Open a new terminal and run the backend server:

cd server
npm install
npm start

5. Install the Expo Go app on your phone and scan the QR code shown in the terminal to open the application.

6. Create a temporary MongoDB Compass database named:

mentalhealth

7. Update the .env file with your MongoDB connection string for the temporary mental-health database before starting the server.
